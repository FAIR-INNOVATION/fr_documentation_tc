Java
============

本文档为Java版本的二次开发接口文档。

.. important::

    机器人参数单位说明：机器人位置单位为毫米(mm)，姿态单位为度(°)。

.. important:: 

    1)	非特別說明的程式碼範例中都預設機器人已經正常開機啟用；
    2)	文件中的所有程式碼範例都預設在機器人的工作空間內沒有任何干涉；
    3)	實際使用測試時請採用現場機器人的數據使用。

.. note:: 
    
    当前文档适用于SDK-v3.7.6版本，向下兼容v1.x/v2.x版本。
