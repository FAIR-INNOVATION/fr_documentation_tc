機器人參數設定
===================

設定安裝方式
--------------------

機器人預設安裝方式為水平安裝，當機器人安裝方式更改時，需及時在「初始設定」->「基礎」->「安裝」選單下設定機器人的實際安裝方式，以保證機器人正常工作。

考慮到更加靈活豐富的機器人部署場景，我們提供了自由安裝功能，用戶點擊「初始設定」->「基礎」->「安裝」，進入機器人安裝方式設定頁面。手動調整「基座傾斜」和「基座旋轉」角度，三維模型會對應展示安裝效果。修改後點擊「應用」按鈕即可完成機器人安裝方式設定。

.. image:: teaching_pendant_software/026.png
   :width: 6in
   :align: center
   
.. centered:: 圖表 3.1-1 機器人安裝

.. important::
    機器人安裝完成後，必須正確設定機器人的安裝方式，否則會影響機器人的拖動功能以及碰撞偵測功能使用。

設定末端負載
--------------------

在「初始設定」->「基礎」->「負載」中「軌跡辨識」的辨識類型，進入末端負載設定介面。

      :width: 0.75in
      :height: 0.75in
      :align: left

   名稱：**應用按鈕**
   
   作用：點擊應用負載編號對應的負載重量和質心座標

.. note:: 
   .. image:: base/072.png
      :width: 0.75in
      :height: 0.75in
      :align: left

   名稱：**修改按鈕**
   
   作用：點擊開啟/關閉辨識運動介面

.. note:: 
   .. image:: base/073.png
      :width: 0.75in
      :height: 0.75in
      :align: left

   名稱：**重新命名按鈕**
   
   作用：重新命名負載名稱

.. note:: 
   .. image:: base/074.png
      :width: 0.75in
      :height: 0.75in
      :align: left

   名稱：**清空按鈕**
   
   作用：清空當前負載資訊（負載重量和質心座標置0）

在配置末端負載時，可直接輸入末端工具的質量以及對應的質心座標X、Y和Z」後點擊「應用」按鈕即可設定。

同時可以點擊「編輯」按鈕，開啟「辨識運動」介面進行負載自動辨識，辨識執行完成後進行應用。

.. important:: 
   負載質量不可超過機器人的最大負載範圍。對應型號負載如下：

   - FR3：3kg

   - FR5：5kg

   - FR10：10kg

   - FR16：16kg
   
   - FR20：20kg
   
   - FR30：30kg

   質心座標設定範圍為0-1000，單位mm。

    機器人末端安裝負載後，必須正確設定末端負載重量以及質心座標，否則會影響機器人的拖動功能以及碰撞偵測功能使用。

設定工具座標
--------------------

在「初始設定」->「基礎」->「工具座標」進入工具座標頁面。

.. note:: 
   .. image:: base/071.png
      :width: 0.75in
      :height: 0.75in
      :align: left

   名稱：**應用按鈕**
   
   作用：點擊應用工具座標系

.. note:: 
   .. image:: base/072.png
      :width: 0.75in
      :height: 0.75in
      :align: left

   名稱：**修改按鈕**
   
   作用：點擊開啟/關閉座標系標定介面

.. note:: 
   .. image:: base/073.png
      :width: 0.75in
      :height: 0.75in
      :align: left

   名稱：**重新命名按鈕**
   
   作用：重新命名工具座標系名稱

.. note:: 
   .. image:: base/074.png
      :width: 0.75in
      :height: 0.75in
      :align: left

   名稱：**清空按鈕**
   
   作用：清空目前工具座標資訊

工具座標可實現工具座標的修改、清空與應用。在工具座標系的下拉清單中，選擇對應的座標系後會在下文顯示對應座標值（座標系名稱可自訂），工具類型以及安裝位置（僅在感測器類型工具下顯示），選擇某一座標系後點擊「應用」按鈕，目前使用的工具座標系變為所選擇的座標，如下所示。

.. image:: base/001.png
   :width: 4in
   :align: center
   
.. centered:: 圖表 3.3-1 設定工具座標

點擊「修改」可根據提示對該編號的工具座標系進行重新設定。工具標定方法分為四點法和六點法，四點法只標定工具TCP，即工具中心點的位置，其姿態預設與末端姿態一致，六點法則在四點法的基礎上增加了兩點，用於標定工具的姿態。

.. image:: base/002.png
   :width: 4in
   :align: center

.. centered:: 圖表 3.3-2 工具座標系標定

.. important:: 
    1. 末端安裝工具後，必須要進行工具座標系的標定及應用，否則會導致機器人執行運動指令時工具中心點的位置和姿態不符合預期值。

    2. 工具座標系一般使用toolcoord1~toolcoord19,應用toolcoord0代表工具TCP的位置中心在末端法蘭中心，在進行工具座標系標定時，首先需將工具座標系應用至toolcoord0，然後選擇其他工具座標系進行標定及應用。
