安全須知
------------

簡介
~~~~~

本說明書會使用到以下警示，這些警示的作用是確保人身及設備的安全，當您在閱讀本說明書時，必須遵守並執行本手冊其他章節中的所有組裝說明和指南，這一點非常重要。應特別注意與警告標誌相關的文字。

.. important:: 
  - 如果機器人（機器人本體、控制箱、示教器或按鈕盒）因人為原因而損壞、更改或修改，法奧意威拒絕承擔所有責任；
  - 法奧意威對因客戶編寫的程式出錯而對機器人或任何其他設備造成的任何損壞概不負責。

人員安全
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

在運行機器人系統時，首先必須確保作業人員的安全，以下列出一般性的注意事項，請妥善採取確保作業人員安全的相應措施。

1. 使用機器人系統的各作業人員，應透過法奧意威（蘇州）機器人系統有限公司主辦的訓練課程接受訓練。使用者需確保其充分掌握安全、規範的操作流程，具備機器人操作資格。訓練詳情請向本公司查詢，電子郵件為 jiling@frtech.fr。

2. 使用機器人系統的各作業人員請不要穿寬鬆的衣服，不要戴珠寶。操作機器人時請確保長髮束在腦後。

3. 在設備運作之中，即使機器人看起來已經停止，也有可能是因為機器人在等待啟動訊號而處在即將動作的狀態。即使在這樣的狀態下，也應該將機器人視為正在動作中。

4. 應在地板上畫上線條來標清機器人的動作範圍，使操作者了解機器人包含握持工具（機械手、工具等）的動作範圍。

5. 確保在機器人操作區域附近建立安全措施（例如，護欄、繩索、或防護螢幕），保護操作者及週邊人群。應視需要設置鎖具，使得負責操作的作業人員以外者不能接觸機器人電源。

6. 在使用操作面板和示教器時，由於戴上手套可能會出現操作上的失誤，請務必在取下手套後進行作業。

7. 在人被機器人夾住或圍在裡面等緊急和異常情況下，透過用力（至少700 N）推動或拉動機器人手臂，迫使關節移動。無電力驅動情況下手動移動機器人手臂僅限於緊急情況，並且可能會損壞關節。

危險識別
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

風險評估應考慮正常使用期間操作人員與機器人之間所有潛在的接觸以及可預見的誤操作。操作人員的頸部、臉部和頭部不應暴露，以免發生碰觸。在不使用外圍安全防護裝置的情況下使用機器人需要先進行風險評估，以判斷相關危險是否會構成不可接受的風險，例如

- 使用尖銳的末端執行器或工具連接器可能有危險；

- 處理毒性或其他有害物質可能有危險；

- 操作者手指有被機器人底座或關節夾住的危險；

- 被機器人碰撞發生的危險；

- 機器人或連接到末端的工具固定不到位存在的危險；

- 機器人有效負載與堅固表面之間的衝擊所造成的危險。

整合商必須透過風險評估來衡量此類危險及其相關的風險等級，並且確定和實施相應的措施，以將風險降低至可接受的水平。請注意，特定機器人設備可能還有其他重大危險。

透過將FR機器人所應用的固有安全設計措施與整合商和最終用戶所實施的安全規範或風險評估相結合，將與FR協作性操作相關的風險盡可能降低至合理可行的水平。透過此文件可將機器人在安裝前存在的任何剩餘風險傳達給整合商和最終用戶。如果整合商的風險評估測定其特定應用中存在可能對使用者構成不可接受風險的危險，整合商必
須採取適當的風險降低措施，以消除或最大限度降低這些危險，直到將風險降低至可接受的水平為止。在採取適當的風險降低措施（如有需要）之前使用是不安全的。

如果對機器人進行非協同性安裝（例如，使用危險工具時），風險評估可能推斷整合商需要在其編程時連接額外的安全設備（例如，安全啟動設備）確保人員及設備安全。

有效性和責任
~~~~~~~~~~~~~~~~

本手冊中的資訊不包含設計、安裝和操作一個完整的機器人應用，也不包含所有可能對此完整的系統的安全造成影響的周邊設備。此完整系統的設計和安裝需符合該機器人安裝所在國的標準和規範中所建立的安全要求。

法奧意威的整合商有責任確保遵循相關國家的法律法規，確保完整的機器人應用中不存在任何重大危險。這包括但不限於以下內容：

- 對完整的機器人系統做一個風險評估

- 將風險評估定義的其他機械和附加安全設備連接在一起

- 在軟體中建立適當的安全性設置

- 確保使用者不會對任何安全措施加以修改

- 確認整個機器人系統的設計和安裝準確無誤

- 明確使用說明

- 在機器人上標明整合商的相關標誌和聯絡資訊

- 收集技術文件中的所有文檔，包括本手冊

使用前評估
~~~~~~~~~~~~~~~

首次使用機器人或進行任何修改之後，機器人預設速度低於250mm/s，請勿登入管理員修改速度進入高速模式，之後必須進行以下測試。確認所有安全輸入和輸出是正確的，並且連接正確。測試所有連接的安全輸入和輸出（包括多台機器或機器人共有的設備）是否功能正常。因此您必須：

- 測試緊急停止按鈕和輸入是否可以停止機器人並啟動煞車。

- 測試防護輸入是否可以停止機器人的移動。如果配置了防護重置，請在恢復運動之前檢查是否需要啟動。

- 測試操作模式是否可以切換操作模式，請參閱使用者介面右上角的圖示。

- 測試3 檔位使動裝置是否必須按下才能在手動模式下啟動動作，且機器人處於減速控制下（機器人軟體版本V3.0前不支援該功能）。

- 測試系統緊急停止輸出是否能夠將整個系統帶到安全狀態。

~~~~~~~~~~~~~~

緊急停止按鈕為0類停機，按下緊急停止按鈕，立即停止機器人的所有動作。

設備運輸
---------

運輸
~~~~~~

機器人和控制箱已作為成套設備校準。請勿將它們分開，那樣將需要重新校準。

只能將機器人放在原包裝中運送。如果今後要搬運機器人的話，請將包裝材料保存在乾燥處。

將機器人從包裝移動到安裝空間時，同時托住機器人的兩個手臂。扶住機器人直到機器人機座的所有安裝螺栓全部緊固好。

搬運
~~~~~~

協作機器人依型號不同，總質量（含包裝）範圍在15kg-80 kg，當人力對協作機器人進行搬運或轉移時，需要多人協助抬起，不建議單人搬運，在運輸過程中務必平穩，避免設備傾翻或滑落。

.. warning:: 
  - 若採用專業設備進行搬運，請務必由具有相應操作資格的專業人員使用吊車或堆高機對協作機器人進行運輸或搬運，否則有可能會造成人員傷害或其他事故。
  - 若採用人工搬運，請注意搬運途中人身安全；
  - 協作機器人包含精密零件，在運輸或搬運過程中應該避免劇烈的振動或晃動，否則有可能降低設備的性能。

存放
~~~~~~~

協作機器人應在-25~60℃，無凝霜環境下存放。

- 關閉並斷開控制箱的電源線。

機器人手臂安裝
~~~~~~~~~~~~~~~~~

.. important:: 
  推薦機器人安裝座符合以下幾個要求，以確保機器人安裝牢固且穩定：

（1）機器人安裝座需要足夠堅固且有足夠的承載能力，至少應該承載5倍的機器人重量，至少能承受10倍的1軸扭力。

（2）機器人安裝座應表面平整，以確保與機器人接觸面緊密接觸；

（3）機器人安裝座應剛度足夠強壯，固定牢固，不會和機器人發生共振；

（4）當機器人和其他部件同時移動時，安裝座與其他運動部件應隔離開，不要固定在一起避免運動過程中的振動幹擾；

（5）如果機器人安裝在移動平台或外部軸上，移動平台或外部軸的加速度應盡量低；

   - 在機器人上法蘭上安裝長度超過8毫米的M6螺栓可能會破壞工具法蘭並造成無法修復的損壞，從而導致必須更換工具法蘭。

安裝環境
~~~~~~~~~~~~~~

安裝及使用協作機器人時，請確保滿足以下要求：

- 環境溫度0-45℃

- 濕度0%~90%RH（無結露）

- 無機械衝擊和震動

- 海拔要求2000m以下

- 無腐蝕性氣體，無液體，無爆炸性氣體，無油污，無鹽霧，無塵埃或金屬粉末，無放射性材料，無電磁噪聲，無易燃物品

- 避免設備在電流的不穩定條件下運作

- 使用者需要在機器人電源前增加空氣開關，同時建議增加EMC濾波器

	如果您要將協作機器人吊起或裝到垂直面時，請聯絡我們。

全系列機型負載曲線
~~~~~~~~~~~~~~~~~~~~~~~~

概述
+++++++++++++

本節所涉及的負載曲線是基於各機箱在特定表格下的測試而得到。各機箱負載曲線存在「完整性能」與「擴展後的負載能力」兩部分，具體如下：

(1) 「完整性能」的運轉環境為：各關節摩擦力補償係數為1；各關節碰撞係數為10；腹板界面設定100%運轉速度及360deg/s2加速度；動力學2.0。在此環境下，負載曲線「完整效能」部分適應剖面運行軌跡。
(2) 若終止能力負載在「擴展後的負載」下，須開啟「時間最優模式」並滿足負載限制，或縮小機器人工作範圍。

參數說明
+++++++++++++

機器人的額定有效負載取決於有效負載的重心偏移，其中，重心偏移定義為終止法蘭中心與附加的有效負載重心之間的距離。

~~~~~~~~~~~~~~~

本節描述了安全I/O的電氣規範，必須遵守第3.5.6節的通用電氣規範。

.. warning:: 
  - 切勿將安全訊號連接到不具有正確安全等級的PLC。如果不遵守此警告，則可能導致嚴重傷害或死亡，因為其中一個安全停止功能可能會被覆蓋。必須將安全介面訊號與正常I/O介面訊號分開。
  - 所有與安全相關的I/O都是冗餘建構的（兩個獨立通道）。必須保持兩個通道分開，以便單一故障不會導致安全功能喪失。
  - 在將機器人投入運作之前，必須先驗證急停安全功能（機器人通電使能，按下急停按鈕，機器人斷電停止，關閉電源，旋轉急停按鈕，打開電源，機器人重新上電使能）。必須定期測試安全功能。
  - 機器人安裝應符合這些規範。否則可能導致嚴重傷害或死亡，因為安全停止功能可能被越過。
