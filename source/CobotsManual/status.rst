系統日誌
----------

首次進入「狀態資訊一一系統日誌」介面，預設展示當天全部類型的日誌資料。

對日誌資料進行等級區分，目前分為:全部、錯誤警告、基礎設定、安全設定、週邊設定、本體操作、示教程序、工具應用、系統設定和檔案匯入匯出。

在資料表格右上角有搜尋輸入框,使用者根據搜尋需求，輸入篩選內容進行篩選。介面如下:

狀態查詢
----------

點選左側選單列「狀態資訊」中「狀態查詢」選單進入狀態查詢介面，查詢類型分為「圖表展示」與「軌跡資料」。如下圖所示：

.. image:: status/002.png
   :width: 6in
   :align: center

.. centered:: 圖表 13.2‑1 狀態查詢

.. note:: 
   .. image:: status/006.png
      :width: 0.75in
      :height: 0.75in
      :align: left

   名稱：**查詢按鈕**

   作用：點選下發查詢圖表/軌跡資料的指令，代表未查詢狀態

.. note:: 
   .. image:: status/007.png
      :width: 0.75in
      :height: 0.75in
      :align: left

   名稱：**右移按鈕**

   作用：點選將左側選取項新增至右側的子項中

.. note:: 
   .. image:: status/008.png
      :width: 0.75in
      :height: 0.75in
      :align: left

   名稱：**刪除按鈕**

   作用：點選刪除右側選取的子項

.. note:: 
   .. image:: status/009.png
      :width: 0.75in
      :height: 0.75in
      :align: left

   名稱：**清空按鈕**

   作用：點選清空右側的所有子項

狀態查詢操作步驟：

**Step1**：點選查詢類型單選按鈕，在參數配置中左側選擇所需查詢的參數，點選「右移」按鈕即可將參數配置到右側清單中。

.. important::
 目前參數配置只能支援新增最多四個待查參數。

.. image:: status/003.png
   :width: 6in
   :align: center

.. centered:: 圖表13.2‑1 參數配置

**Step2**：點選「查詢」按鈕即可查詢資料。

選擇圖表展示後，點選查詢按鈕，下方會依照參數配置即時顯示折線圖。如下圖所示：

.. image:: status/004.png
   :width: 6in
   :align: center

.. centered:: 圖表13.2‑2 圖表展示

選擇軌跡資料後，查詢過程中無折線圖，點選停止查詢按鈕成功停止查詢後，顯示下載按鈕。如下圖所示：

.. image:: status/005.png
   :width: 6in
   :align: center

.. centered:: 圖表13.2‑3 軌跡數據

.. important::
 查詢過程中，切換進入其它介面需要確認是否停止查詢。
